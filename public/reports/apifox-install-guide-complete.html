📥 手动安装步骤

步骤 1: 访问官网

打开浏览器访问：

https://www.apifox.com/

步骤 2: 下载对应版本

| 操作系统 | 下载链接 | 文件名 | |---------|---------|--------| | Windows | https://www.apifox.com/ | Apifox-Setup.exe | | macOS | https://www.apifox.com/ | Apifox.dmg | | Linux | https://www.apifox.com/ | Apifox.AppImage |

步骤 3: 安装

  • Windows: 运行 .exe 文件，按提示安装
  • macOS: 拖拽到 Applications 文件夹
  • Linux:
    chmod +x Apifox.AppImage
./Apifox.AppImage

🔧 配置 CSQAQ API

1. 创建新项目

  1. 打开 Apifox
  2. 点击"新建项目"
  3. 项目名称：CSQAQ API
  4. 点击"创建"

2. 设置环境变量

在项目设置中添加：

| 变量名 | 值 | |--------|-----| | api_base | https://api.csqaq.com/api/v1 | | api_token | KPFDB1P7F8Y3Q6B6I8L4E2P9 |

3. 配置全局 Header

在项目设置 → 前置操作 → Header 中添加：

ApiToken: {{api_token}}
Content-Type: application/json

4. 导入 API 文档（可选）

方式 1: 使用 MCP Server

npx -y apifox-mcp-server@latest --site-id=4711104

方式 2: 手动创建接口 参考下面的接口列表

📋 CSQAQ API 接口列表

根据官方文档，可用接口包括：

系统接口

  • POST /sys/bind_local_ip - 绑定本机白名单 IP ✅

饰品查询接口

  • GET /market/item/search - 联想查询饰品 ID
  • POST /market/item/detail - 获取单件饰品详情
  • POST /market/price/youpin - 悠悠有品价格
  • POST /market/price/batch - 批量获取价格
  • POST /market/price/history - 价格历史

指数接口

  • GET /market/index - 饰品指数
  • GET /market/index/detail - 指数详情
  • GET /market/index/kline - 指数 K 线图

排行榜接口

  • POST /market/rank/list - 获取排行榜
  • POST /market/rank/hot - 热门排行

⚠️ 注意事项

1. 请求频率限制

  • 限制: 1 次/秒
  • 建议: 在 Apifox 中设置延时

2. 401 错误处理

如果返回：

{"code":401,"msg":"请求的地址非法，请更换请求链接"}

可能原因:

  • 接口路径不正确
  • Token 权限不足
  • 接口需要企业权限

解决方案: 联系 CSQAQ 官方（添加 QQ 好友）

3. 429 错误

429 Too Many Requests

原因: 请求频率过快

解决方案: 降低请求频率，添加延时
